# Instrucciones para Claude

El contexto completo de este proyecto (estado, decisiones, arquitectura, bitácora y pendientes)
vive en el repositorio privado **`rianmo80/RAM-Projectos`**, carpeta **`AirMe/`**.

- **Al empezar:** léelo (`AirMe/README.md`, `CONTEXTO.md`, `BITACORA.md`). Si no está clonado en
  este PC, clónalo junto a este repositorio: `gh repo clone rianmo80/RAM-Projectos`.
  En el PC principal está en `D:\Source\repos\RAM-Projectos`.
- **Después de cada commit, versión publicada o decisión importante:** actualiza esa carpeta
  (estado en `README.md`, entrada fechada en `BITACORA.md`, `CONTEXTO.md` si cambió algo de fondo)
  y haz commit + push de `RAM-Projectos`. Sin que el usuario lo pida.
- No guardes la bitácora ni notas privadas en este repositorio: es público.
